# Calculator App

## Welcome the the greatest claculator every made! 

### features 
* Theme toggle
* User input from keyboard (calcualor is smart enuogh to filter white spaces)
* live answer preview
* smart live answer preview
* change button background color when user holds it. 
* TAPPING on "c" will delete one charater from the equation, HOLDING "c" will clear all the equations. 
* can handle with scitific notions (example: 1/999999 would give you 0 inseatd of very small number containing "E")


### notes
* The answer range is -2147483648 to 2147483647
* User can not add negative number in the equation; however they can add a single negative number from getting a negative answer then expanding on that negative equation. 
* Typing equation from keybaord will not show live answer preview.
